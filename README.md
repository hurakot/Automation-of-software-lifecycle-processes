# Автоматизация процессов жизненного цикла программных средств

Дисциплина "Автоматизация процессов жизненного цикла программных средств"

Программа, разработанная в рамках дисциплины "Автоматизация процессов жизненного цикла программных средств" (3 курс, 5 семестр).

Учебный репозиторий, в рамках которого освоены и использованы технологии Python, Flask, SQLAlchemy, PostgreSQL, Docker и т.д.

Backend-часть проекта была написана автором репозитория.

Также в рамках работ, программа была развернута на ВМ Ubuntu Desktop и ВМ Ubuntu Server, работала с TeamCity, был настроен пайплайн CI/CD в TeamCity, в ходе которого программа в других ветках обновлялась при внесении изменений в одной ветке, были настроены миграции, перенос БД и другие вещи.

Dev-Ops часть проекта с развертыванием программы из docker-compose.yaml, на ВМ, написание тестов, реализация CI/CD пайплайна, автоматическое обновление системы в других ветках после реализации изменений в коде и миграций в отельной ветке были реализованы с помощью ИИ.

Данный репозиторий можно включать в резюме и список проектов.
